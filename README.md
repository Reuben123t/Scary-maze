## 🎮 About the Project

**Impossible Maze** is a browser-based 3D horror maze game built using HTML, CSS, JavaScript, and Three.js.

Navigate through mysterious labyrinths, solve the maze, avoid deadly traps, and escape before time runs out. But be careful — the maze changes as you explore!

## ✨ Features

- 🧩 **Procedurally Generated Mazes** – Experience different maze layouts.
- 👻 **Horror Creatures** – Watch out for the Weeping Stalker and Crimson Screamer.
- 🌀 **Shifting Walls** – Maze walls change as you turn around.
- 🔑 **Key Collection** – Find the golden key to unlock the exit.
- ⚠️ **Deadly Traps** – Avoid spikes, fake exits, and teleporting doors.
- 🔦 **3D First-Person Gameplay** – Explore using an immersive 3D environment.
- ⏱️ **Time Challenge** – Complete each level before time runs out.
- ❤️ **Limited Lives** – Survive with three lives.
- 🔊 **Sound Effects** – Experience atmospheric audio.
- 📱 **Mobile Controls** – Play using touch controls on mobile devices.

## 🗺️ Game Levels

| Level | Name | Maze Size |
|---|---|---|
| 1 | The Shifting Cellar | 17 × 17 |
| 2 | The Hall of Hallucinations | 23 × 23 |
| 3 | The Impossible Abyss | 29 × 29 |

Each level introduces more challenging maze layouts and obstacles.

## 🕹️ Controls

| Key | Action |
|---|---|
| W / ↑ | Move Forward |
| S / ↓ | Move Backward |
| A / ← | Move Left |
| D / → | Move Right |
| Mouse | Look Around |
| E / Click | Interact / Open Door |
| Shift | Sprint |
| P | Pause Game |

**Mobile:** Use the on-screen joystick to move and swipe to look around.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Reuben123t/Scary-maze.git
```

### 2. Navigate to the Project

```bash
cd Scary-maze
```

### 3. Run the Game

Open `index.html` in your browser.

Alternatively, use the VS Code Live Server extension to launch the game locally.
